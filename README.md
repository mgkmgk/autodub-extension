# VideoDubber TR

YouTube ve Netflix videolarında yabancı dildeki konuşmaları gerçek zamanlı olarak yakalayıp doğal yapay zeka sesiyle Türkçe seslendiren açık kaynaklı bir Chrome eklentisidir.

## Özellikler

- **Çoklu Platform:** YouTube ve Netflix video oynatıcılarıyla tam uyumlu.
- **Doğal Türkçe Sesler:** Microsoft Edge Neural Türkçe ses modelleri (Ahmet ve Emel).
- **Akıllı Ses Kısma:** Dublaj konuşurken arka plandaki orijinal video sesi otomatik olarak kısılır.
- **Sıfır Kurulum:** Proje içindeki bağımsız çalıştırılabilir program sayesinde Python kurulumu gerektirmez.
- **Ücretsiz & Sınırsız:** Herhangi bir ücretli API anahtarı veya abonelik gerektirmez.

## Kurulum ve Kullanım

### 1. Ses Motorunu Başlatma
Klasörde bulunan `VideoDubber-Ses-Motoru.exe` dosyasına çift tıklayın (arka planda çalışacaktır).

### 2. Eklentiyi Chrome'a Yükleme
1. Google Chrome'da `chrome://extensions/` adresine gidin.
2. Sağ üstteki **Geliştirici modu** seçeneğini açın.
3. **Paketlenmemiş öge yükle** butonuna tıklayıp bu klasörü seçin.
4. YouTube veya Netflix'te bir video açarak dublajı kullanmaya başlayın!
